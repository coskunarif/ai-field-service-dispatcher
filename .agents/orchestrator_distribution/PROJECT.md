# Project: Gainhelm Organic Distribution

## Architecture
This project implements the initial organic distribution channels for Gainhelm.
It consists of marketing assets, templates, and directory listings stored as Markdown files under the target directory `/home/ubuntuadmin/projects/ai-field-service-dispatcher/seo/distribution`.

### Target Files:
1. `database.md`: Platform and directory listings (15+ total, 5+ trade-specific)
2. `templates.md`: Customized outreach and forum templates (3 cold emails, 3 Reddit templates, 2 DMs)
3. `playbook.md`: Step-by-step directory submission checklists, anti-spam guidelines, and tracking tables.
