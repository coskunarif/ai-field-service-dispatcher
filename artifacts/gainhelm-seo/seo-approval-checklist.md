# Gainhelm SEO Approval Checklist

Use this checklist to decide whether to approve the verified SEO metadata update.

## Scope
- Canonical handoff: `artifacts/gainhelm-seo/snippet-implementation-instructions.md`
- Snippet sources:
  - `artifacts/gainhelm-seo/draft-hvac-meta-snippet.md`
  - `artifacts/gainhelm-seo/draft-plumbing-meta-snippet.md`
  - `artifacts/gainhelm-seo/draft-field-service-meta-snippet.md`
- Target HTML files:
  - `hvac-dispatch-software.html`
  - `plumbing-dispatch-software.html`
  - `field-service-scheduling.html`

## Approval decision
- [ ] Approve SEO execution for the mapped HTML files only
- [ ] Reject for now
- [ ] Changes needed first

## What approval means
- Apply only the verified title/meta snippets from the canonical sources above.
- Keep the edit local to the three mapped HTML files only.
- Re-run the post-implementation verification checklist after any approved edit.

## Guardrails
- This checklist does not authorize live edits, deployment, posting, outreach, ads, or email.
- No live/public Gainhelm page has been modified.
- No other files should change.
