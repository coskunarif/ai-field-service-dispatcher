# Reusable Gainhelm SEO Snippet Pattern

## What worked in both branches
- Start from a GSC query/page pair with impressions but no clicks.
- Use one exact or near-exact query phrase in the title.
- Keep the description short and centered on the page’s core job-to-be-done.
- Match the snippet to words already present in the rendered page.
- Verify continuity with the landing page before considering any publish step.

## Required elements
- Target page and query
- GSC evidence
- A draft title
- A draft description
- Supporting page quotes
- No-publish note

## Optional elements
- A short comparison phrase like `best HVAC dispatch software`
- A lightweight CTA only if already supported by the page

## Claims to avoid
- Unsupported iPad/mobile/readable-board claims if the rendered page does not say them
- New benefits not present in the page copy
- Broad promises not tied to service-call scheduling / dispatch workflow

## HVAC example
- Draft title: `Best HVAC Dispatch Software | Gainhelm`
- Draft description: `Gainhelm helps HVAC teams schedule calls, assign technicians, and keep the board readable on iPad or mobile.`
- Supporting page quote: `If you're comparing the best HVAC dispatch software, look for a clean workflow, iPad readability, and fast technician assignment.`
- Continuity result: `The page immediately supports the snippet promise.`

## Plumbing example
- Draft title: `Plumbing Dispatch Software for Service Calls | Gainhelm`
- Draft description: `Gainhelm helps plumbing teams schedule service calls, assign plumbers, and keep the day organized.`
- Supporting page quotes: `Gainhelm gives plumbing teams a clean workflow for job assignment, route planning, and follow-up so the day feels easier to run.` / `Plumbing dispatch app helps teams schedule service calls, assign plumbers, and keep the day organized.`
- Continuity result: `Continuity passes.`
