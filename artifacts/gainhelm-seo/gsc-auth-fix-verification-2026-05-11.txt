Google Search Console CLI for AI agents

Options:

  -h, --help                                   display help for command

Commands:
  query [options] <siteUrl>                    Query search analytics data
  sites                                        List all sites in Search Console
  site <siteUrl>                               Get information about a specific site
  site-add <siteUrl>                           Add a site to Search Console
  site-remove <siteUrl>                        Remove a site from Search Console
  sitemaps [options] <siteUrl>                 List sitemaps for a site
  sitemap <siteUrl> <feedpath>                 Get information about a specific sitemap
  sitemap-submit <siteUrl> <feedpath>          Submit a sitemap for a site
  sitemap-delete <siteUrl> <feedpath>          Delete a sitemap from a site
  inspect [options] <siteUrl> <inspectionUrl>  Inspect a URL's index status
  inspect-batch [options] <siteUrl>            Batch inspect multiple URLs' index status
  help [command]                               display help for command
